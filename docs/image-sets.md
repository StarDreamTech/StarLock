# 图片集与后台管理

2026-11-15 本地实现。系统现有 **23 张图片、5 套图集**：原有品牌原作 3 张，新增「星际光轨」「造物工坊」「自然梦境」「空间实验」各 5 张。新增 20 张均通过内置 `imagegen` 分别生成，以现有紫色锁体、四角星锁孔为参考；标准 Logo 未修改。图片、SHA-256、尺寸与可复用提示词规格见 `server/assets/image-sets/generated.json` 和 `prompts.json`。

## 在后台使用

打开 [本地图片集管理](http://127.0.0.1:8018/admin)。官网体验区也有本地管理入口。后台由 FastAPI 直接提供，不依赖 Vite，适用于服务运营者管理；本版尚无客户账号、多租户隔离和站点管理界面。

- 系统图集：预览、重命名、整套启停、单图启停、设为默认。系统原图不接受覆盖上传。
- 自定义图集：新建 → 批量上传 → 启用 → 设为默认，或复制图集标识给业务后端。
- 「全部系统随机」只选启用的系统图集与图片，自定义图集需要明确选择。
- 系统出厂共 23 张；管理后台若保留上传演示，计数会包含其图片。
- 当前使用停用来下架资源，不提供永久删除。每个自定义图集上限 200 张、最多 50 个自定义图集。

后台用自定义按钮切换图集，没有浏览器原生下拉菜单。验证码本身继续使用现有紧凑弹窗、键盘操作与贝塞尔速度映射。

## 上传规范

静态 PNG / JPEG / WebP，单张最多 **5 MiB**，两边各 **256–4096 px**、总像素不超过 **1200 万**；拒绝动画、损坏文件和近乎纯色的图片。文件扩展名不作为有效性依据，服务端实际解码检查。建议使用不对称、具有可辨认纹理与边界的图片，避免纯色、同心圆和高度重复的图案。纯色检测只是基础质量检查，不能代替图像可解性审核。

服务端自动应用 EXIF 方向、铺平透明背景、转 RGB、缩小至长边不超过 1024 px，再编码为 JPEG；移除原有 EXIF 等元数据。按规范化后的内容哈希在同一图集中去重，并发上传相同内容只保存一份。管理页逐张处理批量上传，分别显示成功、重复和失败；单张失败不会撤销其他成功上传。

自定义图片及图集配置保存在现有 SQLite 数据库。不会用上传文件名拼接磁盘路径，不会执行用户文件。管理预览只通过登录后的缩略图接口提供；新 20 张源图在服务端资源目录，不进入官网静态构建。

## 管理认证与部署

开发模式下，只有同时满足 `STARLOCK_DEBUG=1`、`STARLOCK_DEMO=1`、直接连接来自回环地址且未配置管理口令，才允许点击进入本地后台。仍需同源登录并获取管理会话，不是任意接口免认证。

正式部署配置独立的 `STARLOCK_ADMIN_TOKEN`，至少 32 字符，使用随机口令并保存在服务器环境或密钥管理系统；不要写入仓库、网页或 SDK。不要复用业务站点密钥。未配置时远程管理登录关闭。生产使用 HTTPS；反向代理需正确传递可信协议、Host，并限制后端网络入口。本地服务使用 `--no-proxy-headers`，不会用任意转发头判断来源。

管理会话保存于 Redis，cookie 为 HttpOnly、SameSite=Strict，生产使用 Secure，有效期 1 小时；退出立即作废服务端会话。所有管理写操作检查精确同源 Origin，管理 API 不开放跨域。后台页面使用 CSP、禁止嵌入，并标记 `noindex,nofollow`。口令不写入浏览器本地存储，也不在响应中回显。生产 HTTPS 与实际反向代理配置尚未在本轮验证。

初始化只新增图集相关表与系统资源，保留现有站点数据、管理改名、启停和默认选择。部署须保留：

- `server/assets/admin/`：后台页面、脚本、样式及 Logo。
- `server/assets/image-sets/`：新增 20 张系统图与清单。
- `assets/rotation/`：原有 3 张系统图。
- SQLite 数据库：图集、默认选择、上传图片与原站点记录。
- Redis：短期管理会话、验证码会话与凭证。重启丢失会话需重新登录/验证。

备份 SQLite 时使用数据库一致性备份；仅复制系统图目录不能备份自定义图片。

## 绑定到验证码

由**业务后端**在 `POST /v1/sessions` 中传入 `image_set_id`，示例值须换成后台实际图集标识；认证仍使用业务站点密钥。

```json
{
  "site_key": "site_example",
  "action": "register",
  "context_id": "context_example_123",
  "origin": "https://www.example.com",
  "challenge_type": "rotate",
  "rotation_source": "preset",
  "image_set_id": "system-orbit"
}
```

- `rotate` + `preset`：未指定 `image_set_id` 时，在创建会话时绑定后台默认图库。每次出题随机抽图，整图方向与内圈校正角度独立随机。
- `slider` / `bezier_slider`：传图集标识时从其图片生成拼图；未传时继续使用既有程序场景。
- `rotate` + `procedural`：继续程序生成几何图案，不接受图集参数。
- 字符、数字、算术题不接受图集参数。

前端 HTML、Vue、React 接口无需增加属性。浏览器挑战接口拒绝 `image_set_id`，来源与图集由会话约束。换默认图库不改变已经创建的会话；刷新仍使用原图集，并过滤新停用的图片。图集停用或没有可用图时，后续出题返回 `IMAGE_SET_UNAVAILABLE`，不偷偷切到其他图库；已下发的题面仍可在有效期内校验。后台会阻止停用默认池中的最后一张可用图片，请先切换默认图库。

公开挑战只返回处理后的题面和拼图片段，不包含原图名称、图集标识、素材编号或正确角度。素材源文件可能随项目源码公开，**图库不能当作秘密**。增加图片降低重复率；不能仅凭 20 张新图、模糊或随机旋转宣称可以抵御模型识别或暴力尝试。一次性会话、错误次数、限流与服务端复核继续生效；识别效果和真人完成率需另做评估。

## 本轮核验

57 项后端、39 项前端测试及类型检查、SDK/官网/接入示例构建通过。测试覆盖 23 张素材完整性、并发去重、持久化、默认池事务保护、格式/尺寸/分块上传限制、管理认证与同源检查、私有预览、会话绑定、刷新策略，以及自定义图用于三种视觉题型后的一次性凭证复核。

实际浏览器完成批量上传两张、重复上传去重、启用并设为默认，再从官网的 390 px 弹窗完成自定义图库旋转题和业务后端复核。此流程使用开发环境私有状态核对正确进度，仅用于联调，没有新增答案接口。后台桌面与手机布局另见验证记录。尚未发布公网、未做生产容量或抗识别测试。
