# 星锁 StarLock 项目知识库

## 项目概览

星梦科技的人机验证服务，独立实现，采用 FastAPI、Redis、SQLite 与 TypeScript 托管 SDK，提供 Vue 3 和 React 接入封装。它是验证服务，不只是验证码图片或前端动画。

## 关键约定

- 业务后端创建会话并复核一次性凭证；浏览器成功回调不能替代业务后端放行判断。站点、动作和业务上下文必须绑定。
- 挑战题型由站点策略和服务端控制。空间贝塞尔路径、速度缓动、旋转是不同维度，不能混为一条曲线。
- 框架组件复用同一份托管 SDK；改界面先查看现有浏览器组件，不分叉实现第二套题面。
- 区分本地实现、已运行验证、发布与生产防护效果；有代码不等于已经上线或证明抗识别能力。
- 根目录 `AGENTS.md` 规定知识库的自动维护及“更新skill”流程；只维护有新结论的内容。
